# Переносимое приложение

## Плитка «Избранное», hover разделов и удаление верхнего запуска (9 ноября 2026)

Навигация теперь: «Избранное», «Чертежи», «Сборки», «Лазер».
«Детали» убраны из плиток. Плитка «Избранное» открывает общий список
макросов, отмеченных звёздочкой в любом разделе, и показывает количество
существующих избранных файлов. Повторные добавления не дублируют запись;
удаление через звёздочку обновляет список/счётчик. Под названиями остаются
исходные разделы. Избранное виртуальное — файлы не копируются и не перемещаются.
Сохранение идёт в прежний portable.json по полному пути, старые избранные
сохраняются. Папка «Детали» и её файлы не удаляются: сканер совместим
со старой библиотекой, файлы доступны глобальным поиском и в избранном.

Верхняя кнопка play полностью удалена; в шапке только выбор папки.
Запуск доступен у строки макроса. Все четыре плитки получили прежний
эффект play: акцентный фон, белые название/счётчик/значок, значок +20%
без изменения размеров плитки. Подпись счётчика согласуется с числом:
«1 макрос», «2 макроса», «5 макросов». Адаптивность и общая прокрутка сохранены.

Сборка net48: 0 ошибок и предупреждений. В браузерном макете проверены
новые плитки и счётчик избранного, добавление/удаление из чертежей,
сборок и лазера, подписи источников, пустое избранное, сброс поиска
при переходе в избранное, одна верхняя кнопка папки, hover всех четырёх
плиток с белыми счётчиками и без сдвига, две колонки и вертикальная прокрутка.
Обновлены обычное, hover и компактное превью; данные демонстрационные.
ZIP и SHA-256 пересобраны. WinForms/DPI и COM/VBA после изменения
не запускались в Linux — требуется проверка в Windows.


## Компактное адаптивное окно и общая прокрутка (9 ноября 2026)

Стартовый клиентский размер возвращён к 900 × 600, Source Sans 3 Bold
14 pt, диалог процедуры — 640 × 460. Минимальный внешний размер
основного окна — 480 × 320. Светлый фон кнопок иконок #FCF7F0,
кремовые карточки и яркий акцент сохранены.

Размеры иконок, их кнопок и отступов теперь вычисляются относительно
ширины окна: масштаб ограничен диапазоном 0,8–1,5 от базовых 900 px,
с учётом Windows DPI. При ширине ниже 720 логических px разделы
перестраиваются из четырёх колонок в две. Текст сохраняет читаемый
размер 14 pt; уменьшение высоты не уменьшает иконки дальше.
Все иконки рисуются из векторного источника высокого разрешения
в вычисляемый размер, hover play остаётся относительным (+20%).

Вместо прокрутки только внутри списка добавлен единый внешний viewport:
высота страницы рассчитывается по содержимому, при уменьшении окна
или длинном каталоге появляется вертикальная прокрутка всей страницы.
Шапка, поиск, разделы и последний макрос доступны прокруткой; горизонтальная
прокрутка не требуется. Логика COM/VBA и сохранение настроек не изменены.

Сборка net48 прошла без ошибок и предупреждений. Браузерный макет
проверен: стартовый размер/14 pt, относительные размеры иконок и светлый
фон, две колонки при узкой ширине, вертикальная прокрутка при уменьшении
высоты, доступность последнего элемента в каталоге из 22 записей,
отсутствие горизонтального переполнения, неизменность размера иконок
при изменении только высоты, поиск/избранное/подписи и hover.
Обычное и hover-превью обновлены; compact.png показывает уменьшенное окно
с прокруткой. ZIP и SHA-256 пересобраны. WinForms/DPI, колёсико мыши
и реальные COM/VBA после изменения требуют проверки на Windows;

Диалог процедур оформлен в той же тёмной палитре. Техническая цепочка

Выбранная библиотека получает четыре одноимённые папки. Сканируются корень

Сборка с .NET SDK 8.0.427 и interop NuGet 32.1.0 (API 2024): без ошибок
и предупреждений. Сканер и разбор процедур: 24 проверки. Включены одинаковые

WinForms net48 x64, asInvoker, без регистрации COM/дополнения и WebView2.

## Динамическая папка

Список Portable теперь строится по .swp верхнего уровня выбранной папки, без зависимости от Library/macros.json. Имя — фактическое имя файла. WinForms Timer раз в 2 секунды обновляет список на UI-потоке, пропуская обновление во время запуска; пустая/недоступная папка не оставляет старые записи. Настройки папки и процедур хранятся в LocalAppData/SWToolsHub/portable.json. Папка не изменяется.

Для известных префиксов «Авторазмер»/«Свердловка» сохранены точки входа и требование чертежа. Для остальных вызывается GetMacroMethods, пользователь выбирает точку входа или вводит её вручную; требуется открытый документ. Это не проверяет пригодность документа для стороннего VBA. Выбор процедуры можно изменить отдельной кнопкой.

Проверки сканера: `dotnet run --project addin/tests/folder/Folder.Checks.csproj` (8 проверок, без запуска VBA). Компиляция portable проходит; GetMacroMethods и интерфейс выбора папки ещё требуют проверки Windows. Пользователь подтвердил запуск первого макроса в предыдущей версии, второй не запускался из-за несовпадения ожидаемого имени/расположения файла.

## Выбор модуля и процедуры

Диалог точки входа заменён на TableLayoutPanel с DPI-масштабированием, отдельными ComboBox «Модуль»/«Процедура» и кнопкой повторного запроса GetMacroMethods. Обработчик принимает System.Array (в том числе SAFEARRAY с ненулевой нижней границей), строку, пустой ответ, устраняет дубликаты. Ошибки/пустой ответ отображаются явно. Для известных имён подставляется прежняя точка входа; добавлены алиасы «Сверловка» и «Weldment Drilling». Сохранённая процедура доступна для изменения; ручной ввод остаётся при отсутствии результатов API. Для сверловки известная точка — InsertWeldWithHoles.start.

Сборка net48 прошла без ошибок/предупреждений; 15 проверок сканера и обработки процедур прошли. Реальный ответ GetMacroMethods и новый диалог ещё требуют проверки на Windows. Пустой ответ API не означает, что VBA-проект не содержит других модулей: приложение не разбирает бинарный VBA-проект.
