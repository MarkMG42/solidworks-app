SW TOOLS HUB PORTABLE — БЫСТРЫЙ ЗАПУСК
Актуально: 9 ноября 2026

СКАЧИВАНИЕ И ОБНОВЛЕНИЕ
1. На GitHub откройте installer → SW-Assistant-Portable.zip → Download raw file.
   Либо используйте прямую ссылку из чата/README.
   Code → Download ZIP скачивает исходники всего репозитория, а не программу.
2. Закройте старую программу. Распакуйте ВЕСЬ ZIP в новую папку пользователя.
   Не запускайте EXE из архива. Не удаляйте рабочие макросы старой библиотеки.
3. Запустите SW-Assistant.exe. Рядом должны оставаться DLL, Fonts и инструкция.
   Установка, права администратора, WebView2, Node.js и SDK не нужны.
   Требуется системный .NET Framework 4.8.

БИБЛИОТЕКА
4. Кнопкой папки сверху выберите корень своей библиотеки.
   В новом ZIP подготовлены Library\Macros\Избранное, Чертежи, Сборки, Лазер.
   Авторазмер Рамы.swp и Свердловка.swp относятся к чертежам.
   Папка Детали старой библиотеки поддерживается, файлы из неё доступны поиском.
   Существующие файлы программа не перемещает и не переименовывает.
5. Список обновляется раз в две секунды. Вложенные папки не сканируются.
   Поиск в Избранном ищет по всей библиотеке; в разделе — внутри раздела.
   При узком окне плитки переходят в два ряда. При недостатке высоты — прокрутка.

ИЗБРАННОЕ
6. Звезда у макроса добавляет/удаляет его в общей вкладке Избранное.
   Под названием указан исходный раздел. Файлы не копируются.
   Наличие файла в папке Избранное не заменяет отметку звёздочкой.

ЗАПУСК
7. Откройте один экземпляр SolidWorks обычным способом, не от администратора,
   и копию подходящего документа. Для Авторазмера и Сверловки нужен чертёж.
8. Нажмите ▶ у нужного макроса. Предварительно выбирать строку не требуется.
   В диалоге выберите Модуль и Инструмент / процедуру.
   Стрелка справа смотрит вверх, когда список открыт, и вниз, когда закрыт.
   Текст этих полей нежирный. Поддерживаются клавиатура и ручной ввод.
9. Если SolidWorks не вернул процедуры, используйте известную/сохранённую
   точку входа или введите её вручную. Можно повторно загрузить процедуры.
   Для Авторазмера: FrameCutListDimensionsV3 → main.
   Для Сверловки: InsertWeldWithHoles → start.
10. Нажмите Запустить. Отмена не выполняет макрос. После запуска проверьте чертёж.

ГОРЯЧИЕ КЛАВИШИ
Кнопка клавиатуры рядом с папкой открывает таблицу макросов.
Каждый макрос занимает одну строку; между строками есть разделители.
Поле без назначения показывает «выберете сочетание».
Нажмите поле строки и сочетание Ctrl, Alt или Shift + буква/цифра/F1–F24.
Крестик очищает назначение. «Сохранить» записывает изменения; «Отмена» и Escape отменяют.
Повторяющиеся сочетания подсвечиваются, сохранение заблокировано.
Если сочетание занято другой программой, Windows отклонит его: выберите другое.
Настройки отдельные для каждого пользователя Windows и сохраняются после закрытия.
Открытый SW-Assistant принимает сочетания, даже когда свёрнут или активен SolidWorks.
При закрытом SW-Assistant горячие клавиши не работают. Для первого запуска неизвестного
макроса нужно выбрать процедуру; далее используется сохранённая точка входа.
Пока открыта таблица или другой диалог/выполняется макрос, горячие клавиши не запускают VBA.
Сохранённые назначения вне текущей библиотеки можно удалить в таблице;
для выполнения сначала выберите библиотеку с соответствующим файлом.
Если при старте сочетание занято, программа предупреждает и сохраняет настройку
для исправления, остальные свободные сочетания работают.

НАСТРОЙКИ И ВНЕШНИЙ ВИД
Настройки папки, процедур, избранного и горячих клавиш: %LOCALAPPDATA%\SWToolsHub\portable.json.
При ручном переносе/переименовании файла его полный путь меняется —
может потребоваться заново выбрать процедуру и добавить его в избранное.
Hover начинается через 60 мс; кнопка/значок плавно увеличиваются без сдвига строк.
Bold и Regular шрифты включены в Fonts, устанавливать их в Windows не нужно.

ОГРАНИЧЕНИЯ
Рабочие .swp и CAD-файлы в ZIP не входят. VBA программа не изменяет.
Сборка неподписанная. Последние изменения интерфейса/стрелок и запуск
в SolidWorks после них требуют проверки на Windows. Облачная компиляция
и браузерный макет не подтверждают реальные COM/VBA и DPI.
