ОБНОВЛЕНИЕ: ДИНАМИЧЕСКАЯ ПАПКА
Нажмите «Выбрать корневую папку макросов…» и укажите папку с .swp.
Перекладывать файлы в Library не нужно. Выбор сохраняется.
Показываются только реальные .swp непосредственно в выбранной папке,
без вложенных каталогов. Имя в списке — имя файла без расширения.
Добавления/удаления/переименования появляются в течение двух секунд.
AutoSize и Свердловка распознаются по началу имени (включая «(2)»).
Для нового макроса выберите процедуру, предложенную SolidWorks,
или введите Модуль.Процедура. Выбор сохранится для этого пути.
Кнопка «Выбрать процедуру и запустить…» позволяет изменить его.
Настройки: %LOCALAPPDATA%\SWToolsHub\portable.json.

SW Tools Hub Portable — без установки и прав администратора

1. Распакуйте ВЕСЬ ZIP в свою папку, например Документы\SWToolsHub.
   Не запускайте EXE прямо из окна архива.
2. Положите рабочие Авторазмер Рамы.swp и Свердловка.swp
   в Library\Macros рядом с приложением.
3. Запустите SolidWorks 2025 обычным способом, не от администратора.
   Оставьте один экземпляр SolidWorks. Откройте копию подходящего чертежа.
4. Запустите SWToolsHub.exe. Выберите инструмент и нажмите
   «Запустить в SolidWorks».

Не нужно запускать Setup, устанавливать дополнение в SolidWorks,
WebView2, Node.js или .NET SDK. Нужен установленный в Windows
.NET Framework 4.8 (он требуется также для SolidWorks 2025).
Удаление — удалить распакованную папку, предварительно сохранив макросы.
Это отдельное простое окно; React-интерфейс остаётся в браузерной/Task Pane версии.

Тестовая неподписанная сборка. Компиляция проверена, но Windows,
подключение к SolidWorks и реальные макросы в облаке не проверены.
Сборка использует interop API 2024; совместимость с SW2025 требует приёмки.
Если корпоративная политика запрещает запуск EXE, обойти её приложение
не может; потребуется разрешение вашей ИТ-службы.
Рабочие .swp не входят в публичный архив.
