# Проверка окон расчётов на Windows

Этот тест запускает настоящие WinForms-контролы из `CalculationView.cs`, без SolidWorks. Требуются Windows x64, .NET Framework 4.8 и .NET SDK 8+.

Из корня репозитория:

```powershell
dotnet run --project addin/tests/calculation-ui/Calculation.UiChecks.csproj -c Release -- artifacts/calculation-ui
```

Проверяются все пять расчётов: заполнение первого листа до создания оконных handles, видимость при первом открытии, размеры 900×600 / 800×600 / 640×480 / 480×320 / 1200×800, перенос кнопок, границы выбора листа и таблицы, отсутствие горизонтальной прокрутки основных таблиц при стандартной ширине, переключение каждого листа, сохранность ввода после изменения размера и переключения листов. В указанную папку сохраняются снимки настоящих Windows-окон.

В Linux проект можно только скомпилировать. Реальные проверки выполняет Windows Portable workflow на Windows Server 2022; результат и снимки сохраняются в GitHub Actions. Программный ввод в тесте помечается изменённым и завершается переходом из ячейки — той же границей валидации, что и Tab. Браузерный макет не проверяет жизненный цикл WinForms.
