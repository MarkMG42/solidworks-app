# SW-Assistant — веб-версия

Статическое приложение пяти расчётов. Постоянный адрес после активации GitHub Pages: **https://markmg42.github.io/solidworks-app/**. Windows-программа и её архивы сохранены отдельно.

## Работа

- Слева выберите расчёт, сверху — его лист. Первый лист открывается сразу. Основные таблицы подстраиваются под окно, широкие справочники прокручиваются внутри таблицы и разбиты на страницы по 50 строк.
- Меняйте значения в полях; десятичная запятая и точка поддерживаются. Ввод автоматически сохраняется в текущем браузере. «Сохранить ввод / Открыть ввод» работают с JSON-сеансами, совместимыми с Windows-версией при одинаковой версии формул. CSV содержит весь выбранный лист, включая невидимые страницы справочника.
- «Обновить из Excel» читает `.xlsx`, проверяет формулы и затем предлагает заменить текущий расчёт. Формулы, справочники и исходные значения сохраняются в IndexedDB этого браузера. Неподдерживаемая функция, отсутствующий лист или ошибка расчёта отклоняют импорт целиком. Кнопка «Вернуть встроенные формулы» восстанавливает поставляемую модель.
- Загруженный Excel и ввод не отправляются на сервер и не меняют расчёты других пользователей. Для другого устройства загрузите тот же Excel и сохранённый JSON. Сброс браузерных данных удаляет локальное сохранение; важные исходные данные сохраняйте файлом JSON.
- Для получения новой опубликованной версии нажмите «Обновить приложение» или обновите страницу. Service worker не используется, поэтому он не удерживает старую сборку. Приложение рассчитано на работу по HTTPS в актуальном Chrome/Edge/Firefox; полная работа офлайн не заявляется.
- Браузер не запускает локальные VBA-макросы в SolidWorks. Пункт «Макросы» объясняет ограничение и предлагает Windows-программу.

## Запуск и проверка

Нужен Node.js 24:

```sh
cd web
npm ci
npm test
npm run dev
npm run build
npm run preview
```

`prepare:data` берёт единую проверенную модель из `addin/portable/Calculations/Workbooks.json` и шрифты из Portable; генерируемые данные/сборка не коммитятся. Зависимости фиксируются `package-lock.json`. ExcelJS загружается браузером только при выборе XLSX, не при обычном открытии расчёта. Override `uuid` на 11.1.1 закрывает GHSA-w5hq-g745-h8pq; импорт проверен после замены.

`npm test` проверяет все 5 894 сохранённых результата Excel, 4 363 результата 256 независимых сценариев, ввод/сохранение/сброс/атомарный импорт, повторное чтение всех пяти оригинальных Excel и замену формулы в изменённом файле. Допустимая ошибка: `1e-8 × max(1, |ожидаемое|)`; тексты и логические значения сравниваются точно.

Полная браузерная проверка:

```sh
python -m pip install -r web/tests/requirements.txt
python -m playwright install chromium
# Запустите HTTP-сервер собранного web/dist; ниже URL должен указывать на его корень.
python web/tests/browser_smoke.py --url http://127.0.0.1:4173/solidworks-app/
```

На Linux можно указать установленный Chromium через `CHROMIUM_PATH`. Проверяются пять первых открытий, пересчёт, сохранность после перезагрузки и смены листов, JSON/CSV, применение изменённого XLSX, отказ от неподдерживаемой функции без потери предыдущей модели, возврат встроенных формул, ошибки ввода, пагинация справочника, навигация назад и размеры 1440/1100/900/800/640/480/390. Снимки — `web/test-results/`.

## Публикация GitHub Pages

`.github/workflows/web-pages.yml` после push в `main` устанавливает зависимости через `npm ci`, запускает численные и браузерные проверки, собирает `web/dist` и публикует Pages. При изменении приложения или общей модели достаточно push и успешного workflow; пользователям не нужно скачивать ZIP.

Если Pages ещё не включён и токен workflow не имеет прав создать сайт, владелец один раз выбирает **Settings → Pages → Build and deployment → Source: GitHub Actions**, затем запускает workflow **Web calculations — GitHub Pages → Run workflow**. Видимость репозитория workflow не меняет.

## Инженерные ограничения

Методика, единицы, справочники и ручные поля перенесены из присланных Excel, а не заменены новой методикой. Дискретизация балки, собственный вес и коэффициенты сохранены. Ab/Abn и Ry фасонки задаются вручную, как в Excel. Недостающие сопротивления смятию и высоты гровера DN350/400 PN25 показываются как ошибки данных. Совпадение вычислений не является экспертизой применимости исходной методики к конкретной конструкции.

Импорт поддерживает существующую структуру пяти файлов и только явно реализованные функции Excel. Произвольные макросы, внешние подключения и выполнение JavaScript из формул не поддерживаются. Новая функция требует отдельного расширения движка и проверки.

## Свои Excel-таблицы в левом меню

Нажмите **«＋ Добавить расчёт»**, выберите один или несколько `.xlsx`. Каждый файл добавляется отдельным пунктом слева с именем файла без расширения. При совпадении имён появляется суффикс `(2)`, `(3)` и т. д.; книги и их ввод независимы. Ошибка одного файла не отменяет добавление остальных. Исходная книга не требует адаптации под расчётную модель SW-Assistant: сохраняются её оформление, листы и списки, а поддерживаемые формулы пересчитываются после ввода.

Книга и изменения **автоматически сохраняются в IndexedDB этого браузера**, вместе с выбранным листом и режимом просмотра. После перезагрузки/следующего открытия сайта пункты меню остаются; открытый пункт восстанавливается по адресу страницы. Для переноса на другое устройство используйте «Скачать XLSX». Данные не отправляются на сервер и не синхронизируются между устройствами. Очистка данных сайта/приватный режим/ограничения хранилища могут удалить или запретить локальное сохранение. Ошибка автосохранения явно показана: в этом случае скачайте XLSX перед закрытием.

Для удаления нажмите **× у пункта слева** либо **«Удалить таблицу»** над книгой и подтвердите. Удаляется только копия и ввод в этом браузере; исходный файл на компьютере не меняется. Остальные книги остаются. Прежние пользовательские расчёты, созданные в старом формате, также восстанавливаются; их прежние ввод, переименование, замена модели, JSON/CSV и удаление сохранены для совместимости.

Общие ограничения и возможности новой таблицы описаны ниже. Численные проверки встроенного движка и строгого импорта расчётных моделей сохранены: [отчёт об аудите](CALCULATION-AUDIT.md).

## Интерактивный XLSX с оформлением Excel

«Добавить расчёт» → выберите XLSX → откройте его пункт слева. Подготовка книги под расчёты SW-Assistant не требуется. По умолчанию «Оформление Excel» показывает таблицу с оформлением из файла: исходные цвета и шрифты, обычные заливки и границы, выравнивание и перенос текста, размеры строк и столбцов, объединённые ячейки. Скрытые строки и столбцы скрыты и здесь. Форматы чисел применяются к сохранённым значениям: проценты, денежные суммы, десятичные разряды, даты (системы 1900 и 1904). Шрифт должен быть установлен на устройстве; иначе браузер использует замену. Отображение разделителей и отдельных локализованных форматов может отличаться от Excel.

Щёлкните ячейку: строка `fx` сверху показывает её исходную формулу или значение. При открытии отображаются сохранённые результаты Excel. Неподдерживаемые расчётным движком функции допускаются и не мешают открыть книгу. При отсутствии сохранённого результата показано **«Нет сохранённого результата»**, дополнительно — в строке выбранной ячейки; ноль, FALSE и сохранённая пустая строка различаются. Ошибки Excel показаны исходным кодом. Значения могут быть устаревшими: для обновления пересчитайте и сохраните книгу в Excel. Переключатель «Вид → Список ячеек» показывает адреса, сохранённые значения и формулы вместе.

Выбор листа книги расположен **внизу, под таблицей**, рядом с пагинацией. Вверху остаются вид, имя файла и действия с книгой. «Справка» раскрывает подсказку; «Развернуть» увеличивает рабочую область на всё окно приложения, скрывая боковое меню. «Свернуть» или Escape вне поля ввода возвращают обычный вид.

Для изменения исходных данных выберите ячейку, введите новое **«Значение»** и нажмите **«Применить»** или Enter. Двойной щелчок по ячейке, Enter или F2 переводят фокус в поле ввода. Escape отменяет ещё не применённый ввод. Можно менять числа, текст, TRUE/FALSE, даты и пустые ячейки внутри открытого диапазона. Поддерживаются десятичная запятая/точка, ввод процентов (`12,5%`) и даты `ДД.ММ.ГГГГ` / `ГГГГ-ММ-ДД`. Пустой ввод очищает значение; апостроф в начале задаёт буквальный текст (например `'0012` или `'=текст`). Формулы и защищённые ячейки доступны только для чтения. «Отменить изменение» последовательно отменяет применённый ввод; смена листа/страницы/раздела сохраняет ввод; он автоматически записывается в браузер. Добавление строк/столбцов, редактирование формул и полная проверка всех правил Excel Data Validation пока не реализованы.

Для ячейки с выпадающим списком Excel стрелка появляется **прямо в выделенной ячейке**, а поле «Значение» тоже становится списком. Выбор сразу применяется и запускает доступный пересчёт. Поддерживаются варианты, записанные в правиле, ссылки на диапазон (в том числе на скрытом листе), имена книги и локальные имена листа, относительные ссылки и простые зависимые списки `INDIRECT` (текст, ссылка на ячейку или их объединение через `&`). Читаются обычные и x14-правила, в том числе для пустых ячеек. Числовые и текстовые варианты сохраняют исходный тип, включая текст с ведущими нулями. Выбор вне распознанного списка отклоняется. Сложные динамические источники (например `OFFSET`), внешние книги или источник без актуальных результатов пока не поддерживаются; при выборе ячейки видно «Список недоступен» с причиной. Правила списков сохраняются в скачанном XLSX.

После изменения поддерживаемые формулы пересчитываются проверенным движком, включая межлистовые ссылки. Перед этим движок сверяет доступные исходные результаты с кэшем Excel. Неподдерживаемая формула, несовпадение исходного результата или неподдерживаемая зависимость показываются как **«Не пересчитано»**, ошибка вычисления — **«Ошибка пересчёта»**; причина видна при выборе ячейки. Старое значение не выдаётся за обновлённое. Общий статус сообщает количество пересчитанных и не обновлённых формул. При отмене всех изменений снова виден исходный снимок Excel.

**«Скачать XLSX»** сохраняет копию с изменёнными значениями. Копия формируется точечным изменением XML внутри исходного ZIP, без пересоздания книги через ExcelJS: стили, формулы, изображения/диаграммы и прочие неизменённые части файла сохраняются, даже если просмотрщик их не отображает. В изменённой копии удаляется старый кэш всех формул и включён полный пересчёт при открытии в Excel. Поэтому её повторное открытие в просмотрщике до сохранения в Excel покажет отсутствие сохранённых результатов; новый ввод снова запускает доступный браузерный пересчёт. Исходный файл не перезаписывается. Если изменений нет, скачивается исходная книга. Если автосохранение ещё не завершилось или недоступно, при уходе со страницы появляется предупреждение о несохранённом вводе.

Поддерживаемое **условное форматирование Excel** окрашивает ячейку или всю строку по исходным правилам книги — например, в зелёный при «Проверено» и в красный при «Не проверено». Цвет обновляется при выборе статуса, сохраняется после перезагрузки и корректно возвращается при отмене. Поддержаны правила с формулой на базе доступных операций/функций, сравнения значений, обычные текстовые условия, приоритеты и `stopIfTrue`; формат может менять заливку, шрифт и границы. Цветовые шкалы, гистограммы, наборы значков и неподдерживаемые функции в правилах пока не воспроизводятся. Отсутствующий/неподдерживаемый результат не подставляется как ноль для окраски. Правила условного форматирования остаются в скачанном XLSX без изменений.

Это локальная работа без запуска Excel и передачи книги на сервер. Диаграммы, изображения, сложные узоры/градиенты заливок, поворот текста и точная печатная вёрстка Excel пока не воспроизводятся. Если числовой формат не поддерживается, видно исходное сохранённое значение. На границе страниц объединение обрезается по видимым строкам с повторением содержимого исходной ячейки.

Доступны пустые листы; в режиме листа страницы содержат по 50 исходных строк, в списке — по 50 ячеек. Широкие листы прокручиваются внутри таблицы. Оригинальные байты XLSX и введённые значения хранятся отдельно в браузере, поэтому при восстановлении сохраняются исходные формулы, оформление и результаты для проверки совместимости. Лимиты: 15 МБ, 50 000 ячеек (включая ячейки с оформлением и объединения), 10 000 строк, 100 столбцов. Ошибочный файл не заменяет и не удаляет уже сохранённые книги.

Проверки: `tests/viewer.test.mjs`, `tests/viewer-style.test.mjs`, `tests/viewer_browser.py`, `tests/viewer_style_browser.py`, `tests/viewer-edit.test.mjs`, `tests/viewer_edit_browser.py`, `tests/viewer-list.test.mjs`, `tests/viewer_list_browser.py`, `tests/viewer-conditional.test.mjs`, `tests/xlsx_library_browser.py`. Браузерные проверки включают открытие пяти исходных инженерных XLSX, оформление, объединения через страницу, размеры, скрытые строки/столбцы, форматы чисел, строку формул и узкие экраны. SSF ([лицензия Apache-2.0 вместе с frac](public/licenses/ssf-and-frac.txt)) используется только для форматирования сохранённых чисел, без вычисления формул.


## Изменения меню и Windows-версия

Общая кнопка «Таблицы Excel» убрана: книги открываются собственными кнопками слева, добавление — через «Добавить расчёт». Существующий пункт «Врезки» скрыт из меню, без удаления сохранённого файла. В расчёте длины болта первой карточкой показана расчётная длина (B19), формулы не менялись. В Windows эти функции реализованы нативными WinForms-контролами: книги из браузера переносите скачиванием XLSX и добавлением файлов в EXE.
