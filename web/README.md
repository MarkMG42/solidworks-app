# SW-Assistant — веб-версия

Статическое приложение пяти расчётов. Постоянный адрес после активации GitHub Pages: **https://markmg42.github.io/solidworks-app/**. Windows-программа и её архивы сохранены отдельно.

## Работа

- Слева выберите расчёт, сверху — его лист. Первый лист открывается сразу. Основные таблицы подстраиваются под окно, широкие справочники прокручиваются внутри таблицы и разбиты на страницы по 50 строк.
- Меняйте значения в полях; десятичная запятая и точка поддерживаются. Ввод автоматически сохраняется в текущем браузере. «Сохранить ввод / Открыть ввод» работают с JSON-сеансами, совместимыми с Windows-версией при одинаковой версии формул. CSV содержит весь выбранный лист, включая невидимые страницы справочника.
- «Обновить из Excel» читает `.xlsx`, проверяет формулы и затем предлагает заменить текущий расчёт. Формулы, справочники и исходные значения сохраняются в IndexedDB этого браузера. Неподдерживаемая функция, отсутствующий лист или ошибка расчёта отклоняют импорт целиком. Кнопка «Вернуть встроенные формулы» восстанавливает поставляемую модель.
- Загруженный Excel и ввод не отправляются на сервер и не меняют расчёты других пользователей. Для другого устройства загрузите тот же Excel и сохранённый JSON. Сброс браузерных данных удаляет локальное сохранение; важные исходные данные сохраняйте файлом JSON.
- Для получения новой опубликованной версии нажмите «Обновить приложение» или обновите страницу. Service worker не используется, поэтому он не удерживает старую сборку. Приложение рассчитано на работу по HTTPS в актуальном Chrome/Edge/Firefox; полная работа офлайн не заявляется.
- Браузер не запускает локальные VBA-макросы в SolidWorks. Пункт «Макросы» объясняет ограничение и предлагает Windows-программу.

## Запуск и проверка

Нужен Node.js 24:

```sh
cd web
npm ci
npm test
npm run dev
npm run build
npm run preview
```

`prepare:data` берёт единую проверенную модель из `addin/portable/Calculations/Workbooks.json` и шрифты из Portable; генерируемые данные/сборка не коммитятся. Зависимости фиксируются `package-lock.json`. ExcelJS загружается браузером только при выборе XLSX, не при обычном открытии расчёта. Override `uuid` на 11.1.1 закрывает GHSA-w5hq-g745-h8pq; импорт проверен после замены.

`npm test` проверяет все 5 894 сохранённых результата Excel, 4 363 результата 256 независимых сценариев, ввод/сохранение/сброс/атомарный импорт, повторное чтение всех пяти оригинальных Excel и замену формулы в изменённом файле. Допустимая ошибка: `1e-8 × max(1, |ожидаемое|)`; тексты и логические значения сравниваются точно.

Полная браузерная проверка:

```sh
python -m pip install -r web/tests/requirements.txt
python -m playwright install chromium
# Запустите HTTP-сервер собранного web/dist; ниже URL должен указывать на его корень.
python web/tests/browser_smoke.py --url http://127.0.0.1:4173/solidworks-app/
```

На Linux можно указать установленный Chromium через `CHROMIUM_PATH`. Проверяются пять первых открытий, пересчёт, сохранность после перезагрузки и смены листов, JSON/CSV, применение изменённого XLSX, отказ от неподдерживаемой функции без потери предыдущей модели, возврат встроенных формул, ошибки ввода, пагинация справочника, навигация назад и размеры 1440/1100/900/800/640/480/390. Снимки — `web/test-results/`.

## Публикация GitHub Pages

`.github/workflows/web-pages.yml` после push в `main` устанавливает зависимости через `npm ci`, запускает численные и браузерные проверки, собирает `web/dist` и публикует Pages. При изменении приложения или общей модели достаточно push и успешного workflow; пользователям не нужно скачивать ZIP.

Если Pages ещё не включён и токен workflow не имеет прав создать сайт, владелец один раз выбирает **Settings → Pages → Build and deployment → Source: GitHub Actions**, затем запускает workflow **Web calculations — GitHub Pages → Run workflow**. Видимость репозитория workflow не меняет.

## Инженерные ограничения

Методика, единицы, справочники и ручные поля перенесены из присланных Excel, а не заменены новой методикой. Дискретизация балки, собственный вес и коэффициенты сохранены. Ab/Abn и Ry фасонки задаются вручную, как в Excel. Недостающие сопротивления смятию и высоты гровера DN350/400 PN25 показываются как ошибки данных. Совпадение вычислений не является экспертизой применимости исходной методики к конкретной конструкции.

Импорт поддерживает существующую структуру пяти файлов и только явно реализованные функции Excel. Произвольные макросы, внешние подключения и выполнение JavaScript из формул не поддерживаются. Новая функция требует отдельного расширения движка и проверки.

## Свои расчёты

«＋ Добавить расчёт» слева → выберите `.xlsx` → задайте название. Появится отдельный пункт меню. Все заполненные листы доступны в стандартном переключателе над таблицей. Можно менять заполненные ячейки без формул (включая подписи); формулы вычисляются автоматически. Выпадающие списки Excel сохраняются, логические ячейки показываются списком TRUE/FALSE. Для длинных листов есть страницы по 50 строк, широкие листы прокручиваются внутри таблицы. Панель действий и выбор листов остаются снаружи прокрутки.

Доступны переименование, замена через «Обновить из Excel», удаление, JSON ввода и CSV листа. Замена может иметь другую структуру листов. Несколько окон с одним файлом хранят ввод независимо. Модель и название хранятся в IndexedDB, ввод — в localStorage текущего браузера. Это не сохранение файла в GitHub; очистка данных сайта удалит пользовательские расчёты. Сохраняйте исходный XLSX и важный ввод отдельно.

Произвольный XLSX принимается в пределах поддерживаемого движка: до 15 МБ, 50 000 заполненных ячеек, 10 000 строк и 100 столбцов. Проверяются все формулы; неподдерживаемая функция, цикл, ошибка вычисления или неподдерживаемый тип ячейки (например дата) отклоняют файл целиком. Пустые листы сохраняются для корректных межлистовых ссылок; полностью пустой файл отклоняется. Полная вёрстка Excel, изображения, диаграммы, макросы и внешние подключения не переносятся. Специальные инженерные ограничения пяти встроенных расчётов к своим таблицам не применяются. Windows-версия этой функцией пока не обновлялась.

Регрессия пользовательских окон: `CHROMIUM_PATH=/usr/bin/chromium python web/tests/custom_browser.py --url http://127.0.0.1:4173/solidworks-app/`.

Проверка вычислений и исправленные ошибки: [отчёт от 11 ноября 2026](CALCULATION-AUDIT.md). При наличии сохранённых результатов формул в XLSX импорт сверяет их с вычислениями программы и отклоняет несовпадение.

Оформление: navy, белый текст, оранжевые акценты, локальный Nunito (SIL OFL). Во встроенных расчётах ввод и результаты разделены на две панели; на узком экране они располагаются последовательно. Все результаты доступны прокруткой правой панели. Примечания исходного Excel можно увидеть при наведении на поле. Справочники и свои книги открываются полной таблицей.

## Просмотр XLSX без пересчёта

Отдельный пункт «Просмотр XLSX» → «Открыть XLSX…». Выберите лист: по умолчанию «Лист Excel» показывает исходные столбцы A, B, …, AA и номера строк, включая пустые промежутки. В каждой заполненной ячейке видны сохранённое значение Excel и формула под ним. Переключатель «Вид → Список ячеек» возвращает компактную таблицу адресов, значений и формул. Подготовка книги под структуру расчётов SW-Assistant не требуется. Неподдерживаемые движком функции допускаются, формулы не исполняются. При отсутствии сохранённого результата показано **«Нет сохранённого результата»**; ноль, FALSE и сохранённая пустая строка различаются. Ошибки Excel показаны исходным кодом. Значения могут быть устаревшими: для обновления пересчитайте и сохраните книгу в Excel.

Это просмотр данных с исходными координатами, без редактирования и точного воспроизведения оформления Excel, объединений, диаграмм, изображений и макросов. Даты отображаются в ISO. Доступны пустые листы; в режиме листа страницы содержат по 50 исходных строк, в списке — по 50 заполненных ячеек. Широкие листы прокручиваются внутри таблицы. Файл хранится только в памяти вкладки; после перезагрузки откройте его снова. Лимиты: 15 МБ, 50 000 ячеек, 10 000 строк, 100 столбцов. Ошибочный файл не заменяет предыдущую открытую книгу. Проверки: `tests/viewer.test.mjs` и `tests/viewer_browser.py`.
