# Правила проекта SW-Assistant

- Репозиторий: https://github.com/MarkMG42/solidworks-app. Продукт — SW-Assistant Portable.
- При начале работы прочитать AGENTS.md, README.md и docs/HANDOFF.md; проверить git status, актуальные исходники и последние коммиты. Сохранять изменения пользователя.
- Основной продукт — отдельное Windows x64 WinForms-приложение .NET Framework 4.8, manifest asInvoker. Пользователь работает без прав администратора.
- Не возвращать основной сценарий к установщику, COM-регистрации, Task Pane или WebView2. React frontend и addin/Addin.cs — сохранённые альтернативы, не основной UI.
- Сохранять простую структуру, без серверов и БД. Node.js и SDK — только на машине разработчика, не пользователя.
- Интерфейс, документация и сообщения — на русском. Не начинать дизайн заново: текущий компактный кремовый интерфейс утверждён.
- Для дизайна сначала показывать браузерное превью прямо в чате. Макет не называть снимком Windows-приложения. Изменения ZIP делать после команды пользователя. Макет списков и таблица горячих клавиш утверждены и включены в сборку 9 ноября 2026.
- Подключение к открытому SolidWorks: GetActiveObject, GetMacroMethods, RunMacro2 в главном STA-потоке. Не применять фоновые COM-вызовы, SendKeys или имитацию мыши.
- Не менять VBA, не заменять .swp на .bas, не добавлять рабочие .swp, CAD-файлы, секреты и внутренние адреса в Git. local-macros/ исключена из Git.
- Избранное хранится по полному пути в portable.json. Не перемещать/переименовывать пользовательские макросы автоматически: это ломает сохранённые точки входа и избранное.
- После изменения приложения собрать, выполнить относящиеся проверки, пересоздать installer/SW-Assistant-Portable.zip и PORTABLE-SHA256.txt. Не публиковать старый ZIP с новым исходником.
- Не добавлять bin/, obj/ или локальные рабочие файлы. После существенного изменения обновлять docs/HANDOFF.md фактическими результатами.
- Не заявлять о проверке Windows/SolidWorks/VBA без реального теста. Компиляция API 2024 и браузерный макет не заменяют приёмку SW2025.
- Не менять видимость репозитория. Не выполнять git push без явного разрешения пользователя. Публикация итоговой сборки и документации разрешена в текущем чате 9 ноября 2026; это не постоянное разрешение для будущих чатов.
