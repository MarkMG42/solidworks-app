# Правила проекта SW Tools Hub

- Основной репозиторий: https://github.com/MarkMG42/solidworks-app. Название продукта остаётся SW Tools Hub; локальная папка может называться SWToolsHub или solidworks-app.
- При начале работы прочитать этот файл, README.md и docs/HANDOFF.md, затем проверить git status и актуальные исходники. Предыдущий чат не требуется.
- Писать документацию и сообщения интерфейса на русском языке.
- Сохранять простую структуру: frontend, addin, config, docs. Без серверов и баз данных.
- Интерфейс: React + TypeScript, компактная Task Pane, светлая и тёмная темы, работа от 320 px.
- На macOS поддерживать браузерный деморежим без SolidWorks.
- Этап 1 завершён. Пользователь разрешил переход к подключению SolidWorks. Следующая задача — этап 2; C# Add-in пока не реализован. Не начинать интерфейс заново.
- Будущая интеграция: C#, .NET Framework 4.8, ISwAddin, Task Pane, WebView2, RunMacro2. COM-вызовы только в потоке SolidWorks.
- Не изменять VBA-код, не заменять .swp файлами .bas, не добавлять .swp в Git.
- Не выполнять git push без явного подтверждения пользователя.
- Первичная публикация текущего приложения в MarkMG42/solidworks-app явно разрешена пользователем 7 ноября 2026. Это не постоянное разрешение на будущие публикации.
- Не менять видимость репозитория. Не публиковать макросы, секреты, внутренние серверные адреса, файлы моделей или чертежей. Папка local-macros/ предназначена для локальных рабочих файлов и исключена из Git.
- Не заявлять о проверке SolidWorks до реального тестирования на Windows с SolidWorks 2025.
- Каждый завершённый этап проверять. Для UI: сборка, поиск, категории, избранное, темы, узкая ширина и демозапуск.
- После существенного изменения обновлять docs/HANDOFF.md: фактическое состояние, выполненные проверки, оставшиеся шаги. Не записывать непроверенные предположения как факты.
