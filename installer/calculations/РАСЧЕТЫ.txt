SW-Assistant — макросы и расчёты

Распакуйте весь архив в отдельную доступную для записи папку.
Запустите SW-Assistant.exe на Windows x64 с .NET Framework 4.8.
Excel, Node.js, сервер и права администратора для расчётов не требуются.
Расчёты работают без запущенного SolidWorks. Для VBA-макросов нужен SolidWorks.

Слева всегда доступны шесть пунктов: «Макросы» и пять расчётов.
Нажмите название нужного расчёта напрямую:
1. Стенка трубы: расчёт по давлению и местное смятие.
2. Длина болта: фланцы, болты/шпильки и рекомендуемые позиции метизов.
3. Балка: нормальные и касательные напряжения, прогиб.
4. Болты и швы: расстояние между швами, угловые и стыковые швы,
   болты и фасонка, ослабленная болтами (нижняя часть листа «Болты»).
5. Высота узла.

Внутри каждого расчёта переключайте листы вкладками сверху.
Светлые поля — ввод; серые — подписи, формулы, результаты и справочники.
Расчёт выполняется после подтверждения ввода: Enter, Tab или выход из поля.
Допустимы десятичная запятая и точка. Escape отменяет текущую правку ячейки.
Результаты показываются с точностью отображения исходного Excel;
внутри вычислений используется полная точность чисел double.
Длинные листы прокручиваются по вертикали и горизонтали.
Формулу результата можно прочитать во всплывающей подсказке.

«Сохранить ввод…» сохраняет исходные данные выбранного расчёта в JSON.
«Открыть ввод…» восстанавливает их; другой расчёт/версия формул не принимается.
Переключение расчётов сохраняет текущий ввод до закрытия программы.
После перезапуска ввод нужно открыть из сохранённого JSON.
«Сбросить ввод» возвращает значения исходного Excel для всех листов расчёта.
«Сохранить таблицу…» выгружает текущий лист в CSV с результатами.
Для копирования выделенных ячеек используйте Ctrl+C.

Методика, справочники, единицы и формулы перенесены из пяти присланных Excel.
В частности, Ab/Abn и Ry фасонки на листе «Болты» задаются вручную,
как в исходном файле: изменение диаметра/марки стали не меняет эти поля.
Если исходный Excel не содержит сопротивления смятию для выбранной стали,
программа сообщает об отсутствии данных. Для DN350/400 при PN25
в исходной таблице не задана высота гровера; рекомендация крепежа
для этих сочетаний не выдаётся до уточнения справочника. Недопустимые размеры, деление на
ноль и ошибки формул не считаются успешной проверкой прочности.
Сверка с Excel подтверждает перенос вычислений; она не заменяет проверку
применимости исходной инженерной методики к конкретной конструкции.

Проверка сборки и формул выполнена в Linux. Интерфейс WinForms и работа
с реальным SolidWorks/VBA требуют проверки на Windows.
