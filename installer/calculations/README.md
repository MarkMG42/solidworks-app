# SW-Assistant с расчётами

Отдельная поставка: `SW-Assistant-Calculations.zip`. Распакованная программа: `Portable/SW-Assistant/SW-Assistant.exe`. Запуск: Windows x64, .NET Framework 4.8. Excel для выполнения расчётов не нужен.

Слева постоянно видны «Макросы» и пять отдельных пунктов расчётов; каждый открывается одним нажатием. Все расчётные листы и справочники сохранены; ввод, автоматический пересчёт, выпадающие списки, сброс, сохранение/загрузка ввода JSON и экспорт текущего листа CSV описаны в [инструкции](РАСЧЕТЫ.txt).

## Окна расчётов

Первый лист заполняется сразу при открытии. Компактный шрифт 9 pt, ширина столбцов автоматически следует ширине окна; строки переносят длинные подписи. Кнопки сверху переносятся по строкам. Многострочные вкладки заменены одним списком «Лист», расположенным в пределах окна. У широких справочников горизонтальная прокрутка находится внутри таблицы.

[Регрессионная проверка настоящих WinForms-окон на Windows](../../addin/tests/calculation-ui/README.md) подготовлена и скомпилирована; запуск на Windows в этой Linux-среде не выполнялся.

## Исходные данные и повторение проверки

`Excel/` содержит пять оригиналов пользователя. Их SHA-256 записаны в `addin/portable/Calculations/Workbooks.json`. Документы используются как данные: тексты из них не исполняются как инструкции или скрипты. Импорт сохраняет 5 894 формулы, промежуточные вычисления, справочники и исходные сохранённые результаты. Движок C# поддерживает только функции, нужные этим файлам, и не использует Excel COM.

Из корня репозитория:

```sh
python3 installer/calculations/import_workbooks.py installer/calculations/Excel addin/portable/Calculations/Workbooks.json
dotnet run --project addin/tests/calculations/Calculation.Checks.csproj -- addin/tests/calculations/SpreadsheetScenarios.json
dotnet run --project addin/tests/folder/Folder.Checks.csproj
dotnet run --project addin/tests/hotkeys/Hotkey.Checks.csproj
dotnet build addin/portable/SWToolsHub.Portable.csproj -c Release -p:SolidWorksInteropPath=/path/to/interop
python3 installer/build-portable.py
python3 installer/calculations/package.py
git diff --check
```

Для повторного независимого пересчёта сценариев установите `openpyxl` и LibreOffice; затем выполните `python3 installer/calculations/verify_spreadsheets.py /tmp/sw-oracle --recalculate`. Команда работает с копиями, оригиналы не переписывает. 256 сценариев покрывают все профили/ориентации/опоры балки, крайние положения нагрузки, температурные границы и материалы трубы, DN/PN/типы фланца и крепежа, DN высоты, классы болтов, материалы и электроды. Обычные тесты используют сохранённые независимые результаты и не требуют LibreOffice.

Сравнение чисел: абсолютная ошибка не более `1e-8 × max(1, |ожидаемое|)`, текст и логические значения — точное совпадение. Сначала проверяются все 5 894 сохранённых результата исходных Excel, затем основные результаты каждого изменённого сценария, сохранение/восстановление, атомарность загрузки и ошибки ввода.

## Границы проверки

Сохраняется методика исходных Excel, включая дискретизацию балки на 400 участков, собственный вес, исходные коэффициенты перевода единиц, вручную задаваемые площади болта и Ry фасонки. Проверка совпадения не является экспертизой инженерной методики. Для отсутствующих в исходном Excel сопротивлений смятию отображается ошибка данных. У DN350/400 при PN25 в исходном справочнике отсутствует высота гровера: программа сообщает об этом и не выдаёт рекомендацию длины. Пустой результат поиска отображается как ноль, при этом исходные проверки пустых данных сохраняются.

[Фактические результаты проверки](verification.txt).

Linux подтверждает расчёты и компиляцию net48. Native WinForms, ввод с клавиатуры, диалоги файлов, DPI и реальная работа SolidWorks/VBA требуют приёмки на Windows; их выполнение здесь не заявляется.


Обновление нативных XLSX: пакет содержит все DLL/лицензии для локальных книг, множественного добавления, ввода/списков/окраски и сохранения XLSX в выбранную папку. Последний проверенный архив и SHA обновляет `.github/workflows/windows-portable.yml` только после model/storage и настоящих WinForms-проверок на Windows. Протокол — `verification.txt`; это не проверка SolidWorks/VBA/SW2025.
