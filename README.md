# SW Tools Hub Portable

Переносимое Windows-приложение для запуска локальных VBA-макросов в открытом SolidWorks. Итоговое состояние на 9 ноября 2026.

## Скачать программу

[Скачать SWToolsHub-Portable.zip](https://github.com/MarkMG42/solidworks-app/raw/refs/heads/main/installer/SWToolsHub-Portable.zip)

Это архив программы. **Code → Download ZIP скачивает исходники всего репозитория.**
Можно также открыть `installer/SWToolsHub-Portable.zip` в GitHub и нажать Download raw file.
Распакуйте весь архив в новую доступную для записи папку и запустите `SWToolsHub.exe`. Не запускайте EXE из архива. Установка и права администратора не нужны; требуется .NET Framework 4.8.

## Работа

1. Откройте SolidWorks обычным способом, без прав администратора. Оставьте один экземпляр и откройте копию подходящего документа.
2. Круглой кнопкой папки выберите корень библиотеки. В новом архиве есть `Library/Macros/Избранное`, `Чертежи`, `Сборки`, `Лазер`.
3. Положите рабочие `.swp` в разделы. Авторазмер Рамы и Свердловка относятся к чертежам. Макросы в ZIP не входят.
4. Нажмите ▶ **у нужного макроса**. Выберите модуль и инструмент/процедуру из ответа SolidWorks; если API не дал список, доступен ручной ввод и известная/сохранённая точка входа.
5. Звёздочка добавляет/убирает макрос из общего избранного. Файлы не копируются. Под названием в избранном указан исходный раздел.

Список обновляется раз в две секунды. Сканируются корень и верхний уровень четырёх папок, без рекурсии. Старая папка `Детали` читается для совместимости; файлы из неё доступны поиском и сохранённым избранным.
Папка `Избранное` в архиве не заменяет звёздочки: файлы из любой папки попадают в общий список после отметки. Настройки — `%LOCALAPPDATA%\SWToolsHub\portable.json`.

## Горячие клавиши

Кнопка клавиатуры слева от папки открывает прокручиваемую таблицу «Макрос / Горячая клавиша».
Нажмите поле нужной строки и само сочетание: Ctrl, Alt или Shift вместе с латинской буквой,
цифрой верхнего ряда либо F1–F24. Крестик удаляет назначение. Нажмите «Сохранить»;
«Отмена», Escape и закрытие окна не сохраняют изменения.

Повторяющиеся сочетания подсвечиваются и блокируют сохранение. При сохранении Windows
также проверяет доступность: занятое другой программой или зарезервированное сочетание
не принимается, появляется сообщение. При старте недоступные назначения остаются в файле
настроек, но не включаются; приложение предупреждает, остальные доступны.

Назначения сохраняются отдельно у каждого пользователя Windows в
`%LOCALAPPDATA%\SWToolsHub\portable.json`, поле `Hotkeys`, по полному пути `.swp`.
Они восстанавливаются после перезапуска и сохраняются при обновлении EXE/ZIP.
Не переименовывайте и не перемещайте макросы без необходимости: путь является ключом.
Сохранённые файлы вне выбранной библиотеки видны в таблице как «Нет в текущей библиотеке»;
назначение можно удалить, но такой макрос не запускается до выбора соответствующей библиотеки.

Сочетания глобальные: работают при открытом SW Tools Hub, в том числе когда окно свёрнуто
или активен SolidWorks. Во время редактирования таблицы, выполнения макроса и модальных окон
повторный запуск блокируется. После закрытия приложения клавиши освобождаются.
Запуск использует сохранённую или известную точку входа; для неизвестного макроса без неё
появится обычный диалог выбора процедуры. Сменить процедуру можно через ▶ у строки.

## Продолжить в новом чате

Сначала прочитать [AGENTS.md](AGENTS.md) и [docs/HANDOFF.md](docs/HANDOFF.md). Предыдущая переписка не требуется.

Главный продукт — `addin/portable/`: C#, WinForms, .NET Framework 4.8 x64, `asInvoker`. У пользователя нет прав администратора; не переводить его на установщик или дополнение.

- Главное окно: 900 × 600, минимум 480 × 320, относительные размеры иконок, две колонки при узкой ширине, общая вертикальная прокрутка.
- Навигация: Избранное / Чертежи / Сборки / Лазер. В шапке клавиатура и папка, запуск — у строк и по горячим клавишам.
- Кремовые карточки, терракотовые иконки; hover через 180 ms, переход около 150 ms, круг и значок растут на 20% без сдвига соседей.
- Source Sans 3 Bold 14 pt; выпадающие списки — Regular 14 pt. Оба шрифта входят в ZIP под SIL OFL.
- Последний макет стрелок списков **утверждён и перенесён в программу**. Ограничение предыдущего шага «пока только превью» снято пользователем.

## Файлы и сборка

[Разработчику Portable](addin/portable/README.md), [инструкция Windows](docs/INSTALL.md), [контекст нового чата](docs/HANDOFF.md).

```powershell
dotnet build addin/portable/SWToolsHub.Portable.csproj -c Release -p:SolidWorksInteropPath="C:\Program Files\SOLIDWORKS Corp\SOLIDWORKS\api\redist"
dotnet run --project addin/tests/folder/Folder.Checks.csproj
python installer/build-portable.py
git diff --check
```

Компиляция в облаке использует interop API 2024 (NuGet 32.1.0); актуальная сборка, шрифты, Win32-отрисовка списков, DPI и реальный запуск VBA требуют проверки на Windows с SolidWorks 2025. Ранее пользователь подтвердил рабочую Portable-основу; это не подтверждает все последующие изменения UI.

`frontend/`, `addin/Addin.cs`, Setup и административные скрипты — сохранённые альтернативы. Они не требуются пользователю Portable. Старые этапы и обсуждения сохранены в [истории](docs/HISTORY-2026-11-09.md).
