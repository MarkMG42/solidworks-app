# SW-Assistant Portable

Переносимое Windows-приложение для запуска локальных VBA-макросов в открытом SolidWorks. Итоговое состояние на 9 ноября 2026.

## Веб-версия

Пять расчётов доступны в браузере без установки Excel и скачивания Windows-сборки. Интерфейс, локальное сохранение и обновление формул из XLSX: [инструкция веб-версии](web/README.md). Публикация сайта настроена через [GitHub Pages workflow](.github/workflows/web-pages.yml); адрес после активации — https://markmg42.github.io/solidworks-app/.

## Расчёты из Excel

Версия с левым переключением «Макросы / Расчёты» и пятью расчётами сохранена отдельно: [пакет с расчётами](installer/calculations/SW-Assistant-Calculations.zip), [инструкция и проверка](installer/calculations/README.md). Для расчётов Excel и запущенный SolidWorks не нужны; программа требует Windows x64 и .NET Framework 4.8.

## Скачать программу

[Скачать SW-Assistant-Portable.zip](https://github.com/MarkMG42/solidworks-app/raw/refs/heads/main/installer/SW-Assistant-Portable.zip)

Это архив программы. **Code → Download ZIP скачивает исходники всего репозитория.**
Можно также открыть `installer/SW-Assistant-Portable.zip` в GitHub и нажать Download raw file.
Распакуйте весь архив в новую доступную для записи папку и запустите `SW-Assistant.exe`. Не запускайте EXE из архива. Установка и права администратора не нужны; требуется .NET Framework 4.8.

## Работа

1. Откройте SolidWorks обычным способом, без прав администратора. Оставьте один экземпляр и откройте копию подходящего документа.
2. Кнопкой папки выберите корень библиотеки. В новом архиве есть `Library/Macros/Избранное`, `Чертежи`, `Сборки`, `Лазер`.
3. Положите рабочие `.swp` в разделы. Авторазмер Рамы и Свердловка относятся к чертежам. Макросы в ZIP не входят.
4. Нажмите ▶ **у нужного макроса**. Выберите модуль и инструмент/процедуру из ответа SolidWorks; если API не дал список, доступен ручной ввод и известная/сохранённая точка входа.
5. Звёздочка добавляет/убирает макрос из общего избранного. Файлы не копируются. Под названием в избранном указан исходный раздел.

Список обновляется раз в две секунды. Сканируются корень и верхний уровень четырёх папок, без рекурсии. Старая папка `Детали` читается для совместимости; файлы из неё доступны поиском и сохранённым избранным.
Папка `Избранное` в архиве не заменяет звёздочки: файлы из любой папки попадают в общий список после отметки. Настройки — `%LOCALAPPDATA%\SW-Assistant\portable.json`.

## Горячие клавиши

Кнопка клавиатуры слева от папки открывает прокручиваемую таблицу «Макрос / Горячая клавиша».
Нажмите поле нужной строки и само сочетание: Ctrl, Alt или Shift вместе с латинской буквой,
цифрой верхнего ряда либо F1–F24. Крестик удаляет назначение. Нажмите «Сохранить»;
«Отмена», Escape и закрытие окна не сохраняют изменения.

Повторяющиеся сочетания подсвечиваются и блокируют сохранение. При сохранении Windows
также проверяет доступность: занятое другой программой или зарезервированное сочетание
не принимается, появляется сообщение. При старте недоступные назначения остаются в файле
настроек, но не включаются; приложение предупреждает, остальные доступны.

Назначения сохраняются отдельно у каждого пользователя Windows в
`%LOCALAPPDATA%\SW-Assistant\portable.json`, поле `Hotkeys`, по полному пути `.swp`.
Они восстанавливаются после перезапуска и сохраняются при обновлении EXE/ZIP.
Не переименовывайте и не перемещайте макросы без необходимости: путь является ключом.
Сохранённые файлы вне выбранной библиотеки имеют в подсказке отметку «Нет в текущей библиотеке»;
назначение можно удалить, но такой макрос не запускается до выбора соответствующей библиотеки.

Сочетания глобальные: работают при открытом SW-Assistant, в том числе когда окно свёрнуто
или активен SolidWorks. Во время редактирования таблицы, выполнения макроса и модальных окон
повторный запуск блокируется. После закрытия приложения клавиши освобождаются.
Запуск использует сохранённую или известную точку входа; для неизвестного макроса без неё
появится обычный диалог выбора процедуры. Сменить процедуру можно через ▶ у строки.

Окно горячих клавиш компактное: один макрос на строку, разделители, поля с подсказкой «выберете сочетание». Для длинного списка доступна прокрутка.

Новый значок с тремя кубами встроен в EXE и окно. Настройки сохраняются в `%LOCALAPPDATA%\SW-Assistant\portable.json`. В результатах поиска под названием отображается категория меньшим шрифтом.

## Продолжить в новом чате

Сначала прочитать [AGENTS.md](AGENTS.md) и [docs/HANDOFF.md](docs/HANDOFF.md). Предыдущая переписка не требуется.

Главный продукт — `addin/portable/`: C#, WinForms, .NET Framework 4.8 x64, `asInvoker`. У пользователя нет прав администратора; не переводить его на установщик или дополнение.

- Главное окно: 900 × 600, минимум 480 × 320, относительные размеры иконок, две колонки при узкой ширине, общая вертикальная прокрутка.
- Навигация: Избранное / Чертежи / Сборки / Лазер. В шапке клавиатура и папка, запуск — у строк и по горячим клавишам.
- Светлые панели с контурами, оранжевые иконки #F06424 без кругов; hover через 40 ms, переход около 100 ms, значок растёт на 20% без сдвига соседей.
- Source Sans 3 Regular 14 pt; выпадающие списки — Regular 14 pt. Оба шрифта входят в ZIP под SIL OFL.
- Последний макет стрелок списков **утверждён и перенесён в программу**. Ограничение предыдущего шага «пока только превью» снято пользователем.

## Файлы и сборка

[Разработчику Portable](addin/portable/README.md), [инструкция Windows](docs/INSTALL.md), [контекст нового чата](docs/HANDOFF.md).

```powershell
dotnet build addin/portable/SWToolsHub.Portable.csproj -c Release -p:SolidWorksInteropPath="C:\Program Files\SOLIDWORKS Corp\SOLIDWORKS\api\redist"
dotnet run --project addin/tests/folder/Folder.Checks.csproj
python installer/build-portable.py
git diff --check
```

Компиляция в облаке использует interop API 2024 (NuGet 32.1.0); актуальная сборка, шрифты, Win32-отрисовка списков, DPI и реальный запуск VBA требуют проверки на Windows с SolidWorks 2025. Ранее пользователь подтвердил рабочую Portable-основу; это не подтверждает все последующие изменения UI.

`frontend/`, `addin/Addin.cs`, Setup и административные скрипты — сохранённые альтернативы. Они не требуются пользователю Portable. Старые этапы и обсуждения сохранены в [истории](docs/HISTORY-2026-11-09.md).

В таблице горячих клавиш отображаются только макросы текущей библиотеки. Если файлов нет, показано «Библиотека макросов пуста». Старые назначения сохраняются в настройках, но не создают строки для отсутствующих файлов. Hover: задержка 40 мс, плавный переход около 140 мс; иконки становятся белыми на оранжевом фоне только при наведении.

Настройки старой версии автоматически переносятся из SWToolsHub в SW-Assistant. Старая пустая папка удаляется; посторонние файлы и макросы не удаляются и не перемещаются. Если новый файл настроек уже существует, отличающаяся старая копия сохраняется как portable.legacy.*.json.


## Сочетания и активная модель

Справа от названия видно назначенное сочетание. В узком окне оно показано рядом
с категорией. После изменения горячих клавиш список сразу обновляется.

Над поиском показан статус SolidWorks и тип/имя активного документа, например
«Сборка · УГВС-300М» или «Чертёж · УГВС-300М». Стандартное расширение скрывается,
полный путь доступен в подсказке. Для несохранённого документа используется его заголовок.
Обновление раз в две секунды; во время выполнения VBA и модальных диалогов опрос приостановлен.
Состояния «SolidWorks не найден», «Документ не открыт», «SolidWorks занят» различаются.
Без подключения или активного документа кнопки ▶ недоступны; горячие клавиши при запуске
сохраняют прежние проверки файла и документа.


## Текущая библиотека и компактная шапка

Библиотека по умолчанию — Library/Macros рядом с запущенным SW-Assistant.exe.
Кнопкой папки можно выбрать папку приложения, Library, Macros или раздел внутри Macros:
программа определит корень. Текущий путь виден в подсказке кнопки папки и сообщении
пустой библиотеки. Сканируется корень и верхний уровень разделов, без рекурсии.
При обновлении пустая библиотека старой стандартной распаковки переключается на новую,
если рядом с новым EXE уже есть макросы. Заполненные старые и пользовательские библиотеки
не переключаются автоматически. Файлы не перемещаются и не переименовываются.

В рабочей области нет повторного названия приложения. Вверху — маленький индикатор,
имя активного документа и кнопки клавиатуры/папки. Зелёный индикатор означает подключение
к SolidWorks, красный — отсутствие подключения; подробность доступна при наведении.
Без активного документа отображается «Документ не открыт».
Основной шрифт 11 pt Regular; заголовки 14 pt Semibold.


## Хоткеи в строке макроса

Строка теперь устроена так: ▶ запуск → название/категория → поле хоткея → ☆ избранное.
Нажмите поле «Назначить клавиши» и введите сочетание. Допустимое свободное сочетание
сразу сохраняется в пользовательских настройках. Дубликат или сочетание, занятое Windows,
не сохраняется: рамка становится красной и показана подсказка с причиной.
Backspace/Delete без модификаторов удаляет назначение. Escape отменяет незавершённый
ввод; уже успешно сохранённое сочетание не отменяется. Пока поле активно, глобальные
хоткеи приостановлены; при выходе из поля восстанавливаются.
Повторное нажатие на Чертежи/Сборки/Лазер оставляет текущую категорию.
