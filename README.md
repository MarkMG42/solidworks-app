# SW Tools Hub

**Без прав администратора: [скачать SW Tools Hub Portable ZIP](https://github.com/MarkMG42/solidworks-app/raw/refs/heads/main/installer/SWToolsHub-Portable.zip).** Распакуйте весь архив в свою папку, откройте SolidWorks обычным способом и запустите `SWToolsHub.exe`. Нажмите «Выбрать корневую папку макросов…» и выберите существующую папку с `.swp`: список строится по реальным файлам, обновляется автоматически и показывает их имена. Выбор папки сохраняется. Ничего устанавливать и включать в дополнениях не нужно. Это отдельное простое окно WinForms с поиском и запуском; WebView2/Node/SDK не требуются. Нужен системный .NET Framework 4.8. Windows/SW2025 приёмка ещё не выполнена.


**Windows: [скачать тестовый EXE-установщик](https://github.com/MarkMG42/solidworks-app/raw/refs/heads/main/installer/SWToolsHub-Setup.exe).** Node.js и .NET SDK для него не нужны. Закройте SolidWorks, установите, скопируйте два рабочих .swp в `C:\Program Files\SWToolsHub\Library\Macros`, включите SW Tools Hub в дополнениях. При отсутствии WebView2 установщик загрузит компонент Microsoft; нужен Интернет. Требуется .NET Framework 4.8. Реальный запуск в SolidWorks 2025 ещё не подтверждён; сначала проверяйте на копиях чертежей.

Компактная библиотека VBA-макросов для SolidWorks 2025. Поиск, категории, избранное и две темы в одном интерфейсе.

**Этап 2: подготовлены исходники дополнения SolidWorks.** C# .NET Framework 4.8 x64, Task Pane, WebView2, локальный JSON-каталог и RunMacro2. Браузерный деморежим сохранён. Сборка и реальный запуск дополнения требуют проверки на Windows с SolidWorks 2025; не считать их подтверждёнными проверками браузера.

Для Windows: [краткая инструкция](УСТАНОВКА.txt) и [сборка, установка и приёмка](docs/INSTALL.md). Рабочие `.swp` передаются отдельно и не входят в репозиторий.

Репозиторий: [MarkMG42/solidworks-app](https://github.com/MarkMG42/solidworks-app). Этап 1 завершён; пользователь разрешил начать подключение к SolidWorks. Для продолжения в новом чате Codex прочитайте [AGENTS.md](AGENTS.md) и [docs/HANDOFF.md](docs/HANDOFF.md).

## Получение проекта

```sh
git clone https://github.com/MarkMG42/solidworks-app.git SWToolsHub
cd SWToolsHub/frontend
npm ci
npm run dev
```

Команды выполняются из любой подходящей рабочей папки. Репозиторий называется `solidworks-app`, название приложения — SW Tools Hub.

## Запуск на Mac

Необходим Node.js 22.12+ (либо более новая поддерживаемая версия) и npm.

```sh
cd ~/Desktop/Projects/SWToolsHub/frontend
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. На широком экране панель показана по центру, на узком занимает всё окно. Для проверки Task Pane задайте ширину окна 320–440 px.

```sh
npm run build
npm run preview
```

Предпросмотр собранной версии: http://127.0.0.1:4173. Результат сборки находится в `frontend/dist`. Пути к ресурсам относительные; внешние шрифты, CDN и сервер приложения не используются. Дополнение загружает эту сборку локально через WebView2; Node.js нужен только разработчику.

## Проверка интерфейса

```sh
cd frontend
npx playwright install chromium
npm test
```

Тесты проверяют поиск, категории, пустые результаты, избранное после перезагрузки, темы, настройки, описание макроса, демозапуск и отсутствие горизонтального переполнения при узкой ширине. Playwright используется только при разработке.

Пользовательские настройки хранятся в localStorage текущего браузера и адреса. Демокаталог читается из `config/macros.demo.json`. Настройка сетевого пути сохраняется, но пока не подключает сетевую папку. Обновление списка сообщает об ограничении деморежима.

Проверено 5 ноября 2026 на macOS: TypeScript и production-сборка успешны, все 6 браузерных тестов Chromium прошли. Проверена ширина 320 px. Снимки: [светлая тема](docs/screenshots/light.png), [тёмная тема](docs/screenshots/dark.png), [узкая панель](docs/screenshots/narrow.png).

## Структура и дальнейшая работа

- `frontend/` — React + TypeScript + Vite, обычный CSS, собственные SVG-иконки.
- `config/` — демонстрационный JSON-каталог.
- `addin/` — C# дополнение и сценарии упаковки/установки Windows.
- `docs/` — архитектура, каталог и план установки Windows.

Этап 3: сетевая библиотека, проверка SHA-256 и локальный кэш. Необходимо отдельно тестировать оба этапа на Windows с SolidWorks 2025.
