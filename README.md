# SW Tools Hub

Переносимое Windows-приложение для запуска VBA-макросов в открытом SolidWorks. Написано на **C# / .NET Framework 4.8**, интерфейс — **Windows Forms**. Подключение через официальный SolidWorks API (COM), выполнение — методом `RunMacro2`. Программа не имитирует клавиатуру или мышь и не изменяет VBA-код.

**[Скачать SW Tools Hub Portable](https://github.com/MarkMG42/solidworks-app/raw/refs/heads/main/installer/SWToolsHub-Portable.zip)**

## Краткая инструкция

1. Скачайте Portable ZIP по ссылке выше. Распакуйте **весь архив** в доступную папку, например «Документы\SWToolsHub». Не запускайте EXE непосредственно из архива: рядом должны находиться остальные файлы пакета. Установка, права администратора, WebView2, Node.js и .NET SDK не нужны. Требуется системный .NET Framework 4.8.
2. Откройте SolidWorks 2025 обычным способом, без запуска от администратора. Для однозначного подключения оставьте один экземпляр SolidWorks. Откройте копию подходящего чертежа с необходимой моделью и видами.
3. Запустите `SWToolsHub.exe`. Нажмите нижнюю кнопку **«Выбрать папку макросов…»**. В стандартном окне Windows перейдите к существующей папке с рабочими `.swp` или вставьте путь в адресную строку. Подтвердите выбор: программа запомнит папку между запусками.
4. В списке появятся реальные файлы этой папки; отображаются их имена без расширения. Вложенные каталоги не сканируются. Добавление, удаление и переименование файлов отражаются примерно за две секунды. Используйте строку поиска для фильтрации. Если папка пустая, список тоже будет пустым.
5. Выберите макрос и нажмите **«Выбрать процедуру и запустить…»**. Укажите модуль и процедуру в выпадающих списках. Для сверловки известная точка входа — `InsertWeldWithHoles.start`. При пустом ответе SolidWorks используйте предложенную известную процедуру или ручной ввод. Выбор сохраняется для файла.
6. Дождитесь завершения и проверьте результат на чертеже. Не запускайте макрос повторно во время выполнения. При ошибке сохраните текст сообщения. Для обновления закройте приложение и распакуйте новую версию отдельно; рабочие макросы сохраните. Для удаления достаточно удалить папку программы.

Рабочие `.swp` передаются отдельно: в публичном архиве и репозитории их нет. Настройки выбранной папки и процедур хранятся в `%LOCALAPPDATA%\SWToolsHub\portable.json`.

## Что проверено

Пользователь подтвердил запуск первого макроса в SolidWorks в предыдущей Portable-версии. Текущие сборка C# и 15 проверок сканирования/обработки процедур прошли в облаке. Последние изменения системного диалога и выбора процедур ещё требуют проверки на Windows. Облачная сборка использует interop API SolidWorks 2024; полная совместимость с SolidWorks 2025 не подтверждена. Проверка типа документа не гарантирует пригодность конкретного чертежа для VBA.

## Интерфейс и развитие

Интерфейс можно менять независимо от логики запуска макросов: улучшить расположение элементов, типографику, цвета, добавить иконки и светлую/тёмную тему. Современный дизайн возможен и в текущем WinForms; более гибкий вариант — WPF. При выборе технологии сохраняем запуск без администратора и установки дополнений. Сейчас приоритет — проверить работу макросов; новый дизайн пока не реализован.

## Разработчикам

- [Portable: исходники и сборка](addin/portable/README.md).
- [Подробности запуска и альтернативная установка дополнения](docs/INSTALL.md).
- [Актуальный контекст и границы проверок](docs/HANDOFF.md).
- `addin/portable/` — актуальное отдельное приложение; `addin/` также содержит альтернативное COM-дополнение с Task Pane. Старый EXE-установщик дополнения требует администратора и не нужен для Portable.
- `frontend/` — сохранённый React + TypeScript + Vite демоинтерфейс; его темы, категории и избранное не перенесены в текущий WinForms UI.
- `config/` — демонстрационный каталог; Portable строит список непосредственно по файлам выбранной папки.

Браузерный деморежим на Mac/Windows:

```sh
cd frontend
npm ci
npm run dev
# Сборка и браузерные проверки:
npm run build
npx playwright install chromium
npm test
```

Для разработки UI требуется Node.js 22.12+. Браузерный деморежим не выполняет VBA. Перед изменениями прочитайте [AGENTS.md](AGENTS.md). Рабочие макросы, секреты и CAD-файлы в Git не добавлять.
