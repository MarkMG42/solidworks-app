# Устройство SW Tools Hub

React + TypeScript + Vite сохраняют существующий компактный интерфейс. Браузерный деморежим работает без SolidWorks. Тема, избранное и настройки хранятся в localStorage; повреждённые значения заменяются безопасными значениями по умолчанию. Серверная папка в настройках пока не подключается к выполнению.

## Локальное дополнение

C# COM-класс реализует `ISwAddin`, .NET Framework 4.8/x64. SolidWorks создаёт дополнение, которое создаёт Task Pane и размещает WinForms-контрол WebView2. UI собирается заранее и поставляется в `ui/` рядом с DLL. Виртуальный HTTPS-origin WebView2 отображается на эту локальную папку: сервер и Node.js у инженера не запускаются. Навигация и сообщения ограничены доверенным UI.

Мост использует JSON: UI отправляет `ready` для получения каталога или `run` с `id`; host отвечает каталогом и результатом. UI не выбирает путь, модуль или процедуру исполнения. Дополнение самостоятельно читает `Library/macros.json`, разрешает id и проверяет локальное имя `.swp` в `Library/Macros`. Затем проверяет наличие активного чертежа и вызывает `RunMacro2`. Специфические требования к содержимому чертежа остаются ответственностью конкретного VBA и пользователя.

COM-вызовы выполняются в потоке SolidWorks; асинхронная инициализация WebView2 не переносит их в произвольный worker. Блокировка на стороне host защищает выполнение от повторного входа. Ответ содержит понятное сообщение и статус; UI блокирует кнопки до ответа. Выгрузка закрывает WebView2 и удаляет Task Pane; callbacks отключаются.

## Развёртывание

Пакет содержит DLL и зависимости, WebView2Loader, `ui/`, `Library/macros.json`, пустую `Library/Macros/`, Install/Uninstall scripts. Макросы не включаются в Git и пакет. Установка использует RegAsm x64 и ключи SolidWorks; удаление сохраняет пользовательские файлы. Документация: [INSTALL.md](INSTALL.md).

## Границы проверки и следующий этап

Облачные проверки UI и компиляции не являются проверкой COM, WebView2 под Windows или VBA в SolidWorks 2025. До реальной приёмки на Windows интеграцию нельзя считать проверенной.

Сетевой каталог, SHA-256 обновлений и офлайн-кэш относятся к следующему этапу. Автообновление дополнения, серверы и базы данных не добавляются.
