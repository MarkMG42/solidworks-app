# Устройство SW Tools Hub

## Реализовано: этап 1

Один React-интерфейс без сервера, БД, маршрутизатора или библиотеки компонентов. Vite собирает статические HTML, CSS и JavaScript с относительными ссылками. Сторонние runtime-зависимости — только React и React DOM.

`config/macros.demo.json` импортируется при сборке. Каждая запись содержит стабильный id, название, категорию, описание, файл, модуль, процедуру и тип документа. Записи отображаются универсальным компонентом. Неизвестная иконка заменяется стандартным кубом.

Фильтры поиска, категории и избранного применяются вместе. Тема, избранное и путь к библиотеке сохраняются в localStorage с префиксом `swtools.`. Некорректные сохранённые значения заменяются значениями по умолчанию. При недоступном хранилище интерфейс продолжает работать и сообщает, что настройки не сохраняются.

Кнопка запуска открывает модальное окно деморежима. Ни сетевых запросов, ни загрузки `.swp`, ни COM-вызовов сейчас нет.

## Следующие этапы

Пользователь разрешил переход к этапу 2. Приведённая ниже интеграция пока не реализована.

На этапе 2 C# Add-in создаст Task Pane с WebView2 и загрузит собранный UI из локального дистрибутива. Node.js на Windows инженера не потребуется. Сообщение UI должно передавать только id макроса: дополнение самостоятельно находит утверждённую запись, проверяет файл, документ и блокировку повторного запуска, затем вызывает RunMacro2 в потоке SolidWorks. UI не должен передавать произвольный исполняемый путь.

На этапе 3 дополнение прочитает серверный каталог, проверит SHA-256 файлов и скопирует их во временные файлы. Утверждение обновления должно происходить только после полной проверки. Последняя рабочая библиотека остаётся доступной без сети. Проверка при старте SolidWorks и ручное обновление используют один механизм. Текущий демонстрационный JSON не является готовым форматом безопасного обновления.

Автообновление самого Add-in в первой версии не планируется.
