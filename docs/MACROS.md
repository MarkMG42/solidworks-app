# Каталог макросов

## Демокаталог этапа 1

Файл `config/macros.demo.json` содержит две записи. Чтобы добавить демонстрационный инструмент, добавьте объект в `macros`, сохранив уникальный `id`, затем пересоберите интерфейс. C# и React менять не требуется.

```json
{
  "id": "my-tool",
  "name": "Название инструмента",
  "category": "Чертежи",
  "description": "Краткое описание.",
  "details": "Назначение и необходимые условия.",
  "file": "MyTool.swp",
  "module": "Module1",
  "procedure": "main",
  "requiredDocument": "drawing",
  "icon": "dimensions"
}
```

Категории: `Чертежи`, `Детали`, `Сборки`, `Сварные конструкции`, `Экспорт`, `Другое`. Иконки: `dimensions`, `drilling`, `cube`; неизвестный ключ показывает куб. Избранное связано со стабильным `id`, поэтому не меняйте его при переименовании.

## Первые инструменты

| Инструмент | Рабочий файл | Модуль | Процедура |
| --- | --- | --- | --- |
| AutoSize | Авторазмер Рамы.swp | FrameCutListDimensionsV3 | main |
| Weldment Drilling | Свердловка.swp | InsertWeldWithHoles | start |

Данные предоставлены пользователем. Репозитории: [AutoSize](https://github.com/MarkMG42/autosize), [Weldment Drilling](https://github.com/MarkMG42/WeldmentDrilling). VBA-код не изменяется. Рабочие `.swp` предоставляются отдельно и исключены из Git; исходные `.bas` не заменяют их.

## Общая библиотека — этап 3

План размещения: `\\SERVER\SolidWorks\SWToolsHub\macros.json` и подпапка `Macros` с утверждёнными `.swp`. Администратор будет добавлять файл, описание, модуль, процедуру, условия запуска и SHA-256 в каталог. Дополнение проверит обновление и запустит утверждённую локальную копию.

Серверный каталог, контроль хэшей и кэш ещё не реализованы. Демо JSON не следует публиковать как рабочий каталог без добавления проверок на этапе 3.
