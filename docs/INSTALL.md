# Сборка и установка на Windows

**На этапе 1 доступен только интерфейс. Устанавливаемого дополнения, COM-регистрации и интеграции с SolidWorks пока нет.** Следующие требования — план для этапа 2; пользователь уже разрешил перейти к его реализации.

## Сейчас: проверка интерфейса

На Mac или Windows установите Node.js 22.12+ и выполните в `frontend`:

```sh
npm ci
npm run build
npm run preview
```

Откройте http://127.0.0.1:4173. Это браузерный деморежим, без запуска VBA.

## Среда для будущей интеграции

- Windows x64 с установленным SolidWorks 2025.
- Visual Studio с разработкой для .NET Framework и targeting pack .NET Framework 4.8.
- SolidWorks API interop-сборки соответствующей версии.
- Microsoft Edge WebView2 Runtime и SDK для .NET Framework.
- Рабочие `Авторазмер Рамы.swp` и `Свердловка.swp`, предоставленные отдельно пользователем.

После реализации Add-in инструкция будет дополнена точными командами x64-сборки, регистрации COM, включения автозагрузки и удаления дополнения. Не регистрируйте несуществующую или неподтверждённую DLL.

## Приёмка на Windows на следующих этапах

Проверить создание Task Pane, локальную загрузку UI без Node.js, оба реальных макроса, неверный тип документа, отсутствие файла, повторный запуск, ошибки VBA и выгрузку дополнения. Для сетевого каталога отдельно проверить отсутствие сети, повреждённое обновление и сохранение последнего рабочего кэша.

Ни один из этих интеграционных сценариев на текущем этапе не проверен.
