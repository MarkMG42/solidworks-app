## Продукт и ограничения

SW Tools Hub Portable — отдельный WinForms EXE, C#, .NET Framework 4.8 x64,
manifest asInvoker, без установки и прав администратора. Подключение к уже открытому
SolidWorks через Marshal.GetActiveObject("SldWorks.Application"), GetMacroMethods,
RunMacro2. COM-вызовы в главном STA UI-потоке, без worker/SendKeys/имитации мыши.

У пользователя нет админских прав. Не возвращаться к Task Pane, COM-регистрации,
WebView2, Setup, Node или SDK на его машине. Серверов и БД нет.
Рабочие .swp/VBA и CAD-файлы не публиковать и не подменять .bas.
Макросы в этом облаке отсутствуют, в ZIP их нет. Историческая local-macros/ игнорируется Git.
Все сообщения и документация — на русском.

## Утверждённый интерфейс

- Клиентская область 900 × 600, минимум внешнего окна 480 × 320. Пропорции вручную не фиксируются.
- Избранное / Чертежи / Сборки / Лазер. Детали убраны из навигации.
- В шапке только круглая кнопка папки. Нет верхней кнопки выполнения.
- ▶ у строки запускает конкретный макрос без предварительного нажатия на название.
- Звёздочка добавляет/убирает из общего избранного; под названием указан исходный раздел.
- Иконки/их кнопки и отступы масштабируются по ширине окна (0,8–1,5 от 900 логических px, с DPI).
  При ширине ниже 720 px — две колонки. Уменьшение высоты добавляет прокрутку всей страницы,
  не уменьшает бесконечно иконки/текст. Длинный список должен прокручиваться до последней строки.
- Фон #FDFCF8, карточки/поиск/панель #F8F3E8, границы #E3DCCF, основной текст #24231F,
  вторичный #706D61. Терракотовый акцент #C6532E, избранная звезда #F3B28A.
- Фон кнопок иконок светлый #FCF7F0. Круглая форма не зависит от прямоугольника ячейки.
- Hover: задержка 180 ms, переход примерно 150 ms. У play/папки увеличиваются и круг,
  и значок на 20%, фон акцентный, значок белый, соседние элементы не сдвигаются.
  Для роста зарезервирована область 46 базовых px (круг около 36), колонки 52 px.
  Плитки разделов также получают акцентный фон и белые текст/счётчик/значок; значок растёт.
- Source Sans 3 Bold 14 pt в основном интерфейсе. Модуль/процедура и их списки — Regular 14 pt.
  Bold/Regular TTF и SIL OFL 1.1 включены в Fonts и ZIP, регистрируются приватно для процесса.
- Диалог точки входа: 640 × 520, модуль и инструмент/процедура, повторная загрузка API,
  ручной ввод при отсутствии ответа. Стрелка примерно в 24 логических px от правого края,
  вверх при открытом списке, вниз при закрытом. Последний пункт перенесён из утверждённого превью.

## Карта кода

- addin/portable/Program.cs: главное окно, внешний viewport/вертикальная прокрутка,
  RefreshLayout/относительные размеры, библиотека, настройки, звёзды и RunSelected.
- UiTheme.cs: палитра, загрузка двух TTF, RoundedButton/RoundedPanel, таймеры hover.
- EntryDialog.cs: GetMacroMethods, выбор модуля/процедуры, запасная/сохранённая точка, ручной ввод.
- EntryComboBox.cs: стандартный редактируемый ComboBox с сохранённым native popup/клавиатурой.
  Кастомизированы рамка и стрелка; GetComboBoxInfo/SetWindowPos задают отступ редактора,
  OnDropDown/OnDropDownClosed меняют направление. Это новый Windows-контрол, требует визуальной приёмки.
- MacroFolder.cs: сканер `.swp`, известные имена и требования документа.
- MacroEntry.cs: разбор COM-массивов/строк, точек входа и дубликатов.
- FolderPicker.cs: системный Common Item Dialog с адресной строкой.
- addin/tests/folder/: 27 переносимых проверок сканера/разбора, не выполняют VBA.
- installer/build-portable.py: упаковка готовой Release/net48 сборки и обновление SHA-256.

## Важное исправление запуска

Ранее «Выберите инструмент» появлялось при нажатии play, потому что код использовал
SelectedItem скрытого ListBox, не связанного с карточками. ListBox удалён.
Play передаёт свой Macro прямо в RunSelected(Macro, true). selectedMacro нужен только для
подсветки. Не возвращать зависимость запуска от скрытого списка/индекса.
RunSelected повторно сканирует файл по полному пути и проверяет документ, после диалога
перепроверяет активный документ и файл, блокирует повторный вход, вызывает RunMacro2.
Отмена диалога не исполняет VBA. Реальный запуск после этого исправления агентом не проверен.

## Библиотека и настройки

Новый ZIP и EnsureModules создают Library/Macros/Избранное, Чертежи, Сборки, Лазер.
Сканируются корень и верхний уровень этих папок; вложенные папки не читаются.
Старая папка Детали также читается для совместимости, но автоматически не перемещается/удаляется.
Категория определяется папкой; известные чертёжные файлы в корне попадают в Чертежи,
остальные корневые — Без раздела. У списка Без раздела есть переход с главной; глобальный поиск
на главной ищет по всем файлам, поиск в выбранном разделе — по нему.

Избранное виртуальное: отметка по полному пути файла в настройках, без копирования .swp.
Файл в самой папке Избранное также требует звёздочки для попадания в общий список.
Папка Избранное заменила Детали в новом архиве; старые пути специально не мигрируются.
Настройки: %LOCALAPPDATA%\SWToolsHub\portable.json: Folder, Entries, Favorites.
После ручного переноса/переименования файла требуется заново выбрать процедуру/избранное.
Сканирование таймером раз в 2 секунды, пропускается во время выполнения макроса.

| Макрос | Известное имя | Модуль | Процедура |
| --- | --- | --- | --- |
| AutoSize | Авторазмер Рамы.swp | FrameCutListDimensionsV3 | main |
| Сверловка | Свердловка.swp / Свердловка (2).swp | InsertWeldWithHoles | start |

Поддерживаются префиксы Свердловка, Сверловка, Weldment Drilling. Не требовать переименования.
Для известных макросов и категории Чертежи проверяется drawing; для остальных нужен активный
документ. Это не проверяет пригодность геометрии/видов для конкретного VBA.

## Сборка и артефакт

Пользователь скачивает installer/SWToolsHub-Portable.zip через Download raw file
или прямую ссылку в README; Code → Download ZIP скачивает исходники.
Архив распаковать весь в новую папку; сохранить старые макросы и выбрать старую библиотеку.
В ZIP: EXE, EXE.config, SolidWorks.Interop.sldworks.dll, Fonts/Bold+Regular TTF,
лицензия, русская инструкция, четыре пустые папки. Рабочих макросов нет.
После любого изменения приложения: сборка → относящиеся проверки → ZIP → checksum.

```powershell
dotnet build addin/portable/SWToolsHub.Portable.csproj -c Release -p:SolidWorksInteropPath="C:\Program Files\SOLIDWORKS Corp\SOLIDWORKS\api\redist"
dotnet run --project addin/tests/folder/Folder.Checks.csproj
python installer/build-portable.py
git diff --check
```

В текущем облаке использованы SDK 8.0.427 в /workspace/work/tooling/dotnet,
CLI_HOME /workspace/work/tooling/dotnet-home, NUGET_PACKAGES /workspace/work/tooling/nuget,
interop /workspace/work/tooling/interop/lib/netstandard2.0. Пути могут отсутствовать в новом окружении.
Interop NuGet 32.1.0 — API 2024, не обязательная Windows-проверка interop SW2025.
.NET в этом sandbox потребовал разрешённого запуска вне sandbox из-за mutex NuGet-Migrations.
