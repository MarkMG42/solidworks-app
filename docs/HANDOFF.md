# Продолжение разработки в новом чате Codex

Актуализировано 7 ноября 2026. Этот файл и AGENTS.md содержат необходимый контекст без доступа к предыдущему чату.

## Проект и рабочая среда

- Продукт: SW Tools Hub — компактная библиотека 30–50 корпоративных VBA-макросов внутри SolidWorks 2025.
- Репозиторий: https://github.com/MarkMG42/solidworks-app, основная ветка `main`.
- На исходном Mac проект находится в `~/Desktop/Projects/SWToolsHub`. На другой машине использовать фактический путь клонирования.
- Основная разработка UI — на macOS; сборка и реальная проверка дополнения — на Windows с SolidWorks 2025.
- Пользователь попросил перейти к подключению SolidWorks. Повторное согласование начала этапа 2 не требуется.
- Пользователь отдельно разрешил первичную публикацию текущего приложения в этот репозиторий 7 ноября 2026. Для следующих публикаций требуется новое явное разрешение.

## Что готово

Этап 1 реализован: React + TypeScript + Vite, обычный CSS и собственные SVG-иконки. Runtime-зависимости — React и React DOM. Без сервера, БД, UI-библиотеки и внешних шрифтов.

- Светлая и тёмная темы.
- Поиск по имени, категории, избранное и пустые состояния.
- Раскрываемые описания AutoSize и Weldment Drilling.
- Настройки: тема, серверный путь и версия. Тема, путь и избранное сохраняются в localStorage.
- Обработка некорректных локальных настроек и предупреждение при запрете сохранения.
- Демозапуск с честным сообщением: макрос не запускался, реальный запуск возможен внутри SolidWorks.
- Адаптация к узкой панели, включая 320 px.

Каталог `config/macros.demo.json` импортируется при сборке. Новая демонстрационная запись не требует изменения C# или React. Серверный путь в настройках сейчас только сохраняется. Кнопка обновления сообщает об ограничениях деморежима.

Сборка выдаёт статический каталог `frontend/dist` с относительными ссылками. Для будущего рабочего места инженера Node.js не нужен: Add-in должен загружать готовый UI локально через WebView2.

## Что НЕ реализовано

В `addin/` пока только README. Нет C# проекта, ISwAddin, COM-регистрации, Task Pane, WebView2, моста UI ↔ C#, вызова RunMacro2 или установщика. Нет серверного каталога, SHA-256-проверки, локального кэша макросов и обновлений. Не заявлять, что приложение уже работает внутри SolidWorks.

Рабочие `.swp` не получены. Пользователь прислал две ссылки ChatGPT Library, но обе перенаправили на вход; файлы не были скачаны и их содержимое не проверено. Ссылки аккаунта не публикуются. Файлы можно передать вложениями или разместить в исключённой из Git папке `local-macros/`.

Неизвестно, где находится Windows с SolidWorks: отдельный компьютер, удалённая машина или Windows на Mac. Реального доступа к такой системе в предыдущем чате не было. Также не получен тестовый чертёж с подходящей моделью.

## Запуск и проверки

Из корня клона:

```sh
cd frontend
npm ci
npm run dev
```

Интерфейс: http://127.0.0.1:5173. Сервер слушает только localhost. Остановка — Ctrl+C. Не полагаться на процессы, запущенные в старом чате.

```sh
npm run build
npm run preview
```

Предпросмотр сборки: http://127.0.0.1:4173. `dist` не включается в Git.

```sh
npx playwright install chromium
npm test
```

6 тестов проверяют сочетание поиска и категорий, сохранение избранного, темы и серверного пути, оба демозапуска, раскрытие описаний, закрытие диалога Escape, отсутствие переполнения при 320 px и повреждённые настройки.

5 ноября 2026 на macOS успешно выполнены TypeScript-проверка, production-сборка и 6 тестов Chromium; production UI проверен без ошибок JavaScript. 7 ноября 2026 перед публикацией production-сборка и все 6 тестов повторно прошли. Снимки светлой, тёмной и узкой панелей находятся в `docs/screenshots/`. В той сессии Chromium устанавливался во временную папку `/private/tmp/swtools-playwright` с переменной `PLAYWRIGHT_BROWSERS_PATH`; на новой машине установить браузер заново обычной командой выше. Не зависеть от временных путей старой машины.
